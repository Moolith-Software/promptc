# Refund policy

## Eligibility

- Monthly plans can be refunded within 14 days of a charge.
- Annual plans can be refunded within 30 days of purchase, pro-rated after that.
- Trial accounts are never charged, so there is nothing to refund.

## How to request

The customer can request a refund from **Billing → Invoices** in {{ company.product }}.
If they can't access billing, you can start the request for them.

## Exceptions

Refunds outside these windows need approval from {{ company.escalation.email }}.
